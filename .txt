What the important directories do
Directory	Responsibility
apps/api	Accept requests, authenticate users and return responses.
apps/worker	Execute long-running geospatial jobs outside the API process.
apps/scheduler	Dispatch eligible jobs and recover expired worker leases.
geocloud/domain	Define business rules for jobs, tenants, datasets and webhooks.
geocloud/geospatial	Implement the actual GIS algorithms and data validation.
geocloud/infrastructure	Handle PostgreSQL, Redis, object storage and observability integrations.
geocloud/security	Enforce access control, API-key validation and tenant isolation.
tests/resilience	Verify recovery from crashes, timeouts and partial failures.
deploy	Store deployment and monitoring configuration.
